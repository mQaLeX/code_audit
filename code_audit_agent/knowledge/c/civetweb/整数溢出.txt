整数溢出
检查代码中是否存在整数溢出漏洞。整数溢出可能导致意外的内存分配、缓冲区溢出或逻辑错误。

具体审计要点：
- 检查算术运算是否可能产生溢出
- 分析整数类型转换是否安全
- 验证内存分配大小是否经过检查
- 检查循环计数器是否可能被操纵
- 分析数组索引是否安全

常见漏洞模式：
- malloc(user_size); // user_size可能被操控导致溢出
- ptr = malloc(n * sizeof(struct)); // n * sizeof可能溢出
- int len = atoi(user_input); // 用户输入转换为整数
- memcpy(ptr, data, len); // len可能超出实际数据大小
- array[index] = value; // index可能越界

CivetWeb特定场景：
- Content-Length解析整数溢出
- HTTP请求头大小字段溢出
- 文件上传大小限制绕过
- WebSocket帧长度解析溢出
- JSON解析时整数溢出

修复建议方向：
- 使用安全的整数类型（如size_t, int64_t）
- 在运算前进行溢出检查
- 使用checked_add, checked_mul等安全算术函数
- 对用户输入的长度进行严格验证
- 启用编译器整数溢出检查选项
