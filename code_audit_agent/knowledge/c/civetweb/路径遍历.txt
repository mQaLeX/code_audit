路径遍历
检查代码中是否存在路径遍历（Path Traversal）漏洞。攻击者可以通过构造特殊的URL路径来访问服务器上的任意文件。

具体审计要点：
- 检查文件操作函数是否正确验证路径
- 分析用户输入是否直接用于构造文件路径
- 验证是否进行了路径规范化检查
- 检查是否存在".."等路径遍历序列的过滤
- 分析文件类型和访问权限是否正确验证

常见漏洞模式：
- fopen(user_input, "r"); // 用户可直接控制文件路径
- include(user_input); // PHP等语言的路径包含
- open(path, O_RDONLY) // path包含用户输入
- readfile(user_filename); // 直接使用用户输入读取文件
- stat(user_path); // 获取用户指定路径的文件信息

CivetWeb特定场景：
- 静态文件服务时未正确验证文件路径
- 文件下载功能路径可被绕过
- 日志文件路径处理不当
- 配置文件路径遍历
- 上传文件保存路径验证不足

修复建议方向：
- 使用realpath()规范化并验证路径
- 建立白名单，允许访问的文件列表
- 过滤路径中的".."序列
- 使用安全的文件访问API
- 检查最终路径是否在允许的目录内
